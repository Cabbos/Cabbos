## Current Focus

### [Forge - Local-first AI Agent Workbench](https://github.com/Cabbos/forge)

Forge is a Tauri + Rust + React/TypeScript desktop workbench for AI coding agents.

It focuses on the product and runtime layer around agent execution:

- multi-provider agent execution and provider readiness
- filesystem, shell, search, diff, and review-oriented tool surfaces
- permission gates, workspace safety, write boundaries, and checkpoints
- session history, resume, diagnostics, scheduler, and background task status
- append-only runtime event journal, rebuildable projections, policy/budget preflight, durable human gates, and completion evidence
- A2A review summaries, sub-agent runtime facts, file-IO evidence, and eval/backtest integration

Forge is also the home for `apps/eval-runner`, a Python/FastAPI backtest and trace evaluation service for coding-agent workflows.
